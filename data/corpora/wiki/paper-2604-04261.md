# APPA: Adaptive Preference Pluralistic Alignment for Fair Federated RLHF of LLMs

**Authors:** Mahmoud Srewa, Tianyu Zhao, Salma Elmalaki  
**ArXiv:** 2604.04261  
**Year:** 2026

## Summary

This paper introduces APPA (Adaptive Preference Pluralistic Alignment), a framework for fair reward aggregation in Federated [[rlhf]] (FedRLHF) that addresses systematic under-alignment of worst-performing groups. APPA dynamically reweights group-level rewards based on historical alignment performance without requiring access to raw preference data.

## Key Problem

### Federated RLHF Challenges
- **Privacy Preservation**: Groups align shared policy without centralizing preference data
- **Fairness Gap**: Average aggregation systematically under-aligns worst-performing groups
- **Min Aggregation Limitations**: Prioritizes worst-group at cost of overall alignment

### Pluralistic Alignment Need
LLMs must respect values of multiple distinct groups simultaneously, addressing demographic, cultural, and geographic preference diversity.

## APPA Framework

### Adaptive Reward Aggregation
Replaces fixed aggregation with dynamic weighting:
```
Aggαt(rtj) = {
  1/|Gtrain| Σ rtg,j     if FI ≥ τ
  log(1/|Gtrain| Σ exp(αtg · rtg,j))  otherwise
}
```

### Fairness Index (FI)
Quantifies reward disparity using coefficient of variation:
- **FI = 1**: Identical rewards across groups
- **FI → 0**: Increasing inter-group disparity
- **Threshold τ = 0.99**: Determines when adaptive weighting activates

### Historical Alignment Tracking
**Exponential Moving Average**: htg = λ · ht-1g + (1-λ) · r̄tg with λ = 0.8

**Reverse Softmax Weighting**: Higher weights assigned to under-aligned groups while maintaining non-zero weights for well-aligned groups

## Experimental Results

### Datasets and Models
- **Tasks**: GLOBALQA and OQA question answering
- **Models**: Gemma-2-2B, Llama-3.2-3B, Qwen3-0.6B
- **Groups**: Countries (GLOBALQA) and demographic clusters (OQA)

### Performance Improvements
- **Worst-Group Alignment**: Up to 28% improvement over average aggregation
- **Overall Alignment**: Higher than min aggregation across most configurations
- **Fairness-Alignment Trade-off**: Consistent improvements in both dimensions

## Technical Innovation

### Privacy-Preserving Design
- Operates entirely on group-level rewards
- No access to raw preference data required
- Maintains federated learning privacy guarantees

### Continuous Adaptation
- Dynamic weight adjustment based on alignment history
- Prevents both majority bias and over-emphasis on worst performers
- Stable training through EMA smoothing
