# Relational Preference Encoding in Looped Transformer Internal States

**Authors:** Jan Kirin  
**ArXiv:** 2604.09870  
**Year:** 2026

## Summary

This paper investigates how looped transformers encode human preference in their internal iteration states. Using Ouro-2.6B-Thinking, the authors demonstrate that preference information is encoded relationally rather than as absolute properties of individual responses.

## Key Findings

### Relational Encoding Discovery
- **Pairwise Success**: Lightweight evaluator achieves 95.2% test accuracy on frozen 2.6B model
- **Independent Failure**: Best nonlinear independent evaluator reaches only 65% accuracy
- **Linear Probe Ceiling**: L-BFGS probe on pairwise differences: 84.5% (lower bound, not ceiling)
- **Below-Chance Independent**: Linear independent classification: 21.75% (inverted polarity)

### Architecture and Training
- **Frozen Base Model**: Only ~5M evaluator parameters trained, 2.6B base completely frozen
- **Loop State Extraction**: Uses forward hooks to capture 4 iteration states per input
- **Feature Engineering**: Attention pooling + GRU constructs rather than destroys preference signal

## Methodological Contributions

### Training Metric Deflation
- **Hidden Problem**: 50% argument-swap protocol deflated pairwise training metrics by ~31 points
- **False Ceiling**: Created appearance that pairwise and pointwise evaluators shared same ceiling
- **Accidental Early Stopping**: Cosine schedule's dead zone at epoch 2 preserved generalization peak
- **Overfitting Pattern**: Test accuracy: 83.3% (epoch 1) → 95.2% (epoch 2) → 62.4% (epoch 5)

### Flip Test Diagnostic
- **Antisymmetry Correlation**: Stable ρ = -0.92 to -0.97 across epochs (robust primary metric)
- **Sign Flip Rate**: Tracks scorer bias rather than genuine preference learning
- **Degenerate Detection**: Can identify 100% accuracy through constant output that standard metrics miss

## Technical Details

### Implementation
- **Model**: Ouro-2.6B-Thinking (only public looped transformer with accessible iteration states)
- **Dataset**: Anthropic HH-RLHF (50k training, 8.5k test)
- **Hardware**: Single RTX 5070 Ti (12GB VRAM)
- **Storage**: 360GB raw hidden states for 50k examples

### Architecture Search
- **Systematic Evaluation**: 9 architectures, 19 configurations, 3 loss functions
- **Genuine Ceiling**: 70% for independent (pointwise) scoring established through comprehensive search
- **Pairwise Advantage**: Demonstrates fundamental representational difference

## Implications

- **Interpretability**: Preference monitoring as separable, interpretable module
- **Efficiency**: Lightweight external evaluators without base model modification
- **Relational Nature**: Challenges assumptions about how models encode comparative judgments

## Related Work

Parallels Anthropic's finding of 171 functional emotion representations in Claude Sonnet 4.5, extending interpretability research to iterative architectures and preference encoding specifically.
