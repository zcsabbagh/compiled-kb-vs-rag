# Offline Constrained RLHF with Multiple Preference Oracles

**Authors:** Brenden Latham, Mehrdad Moharrami  
**ArXiv:** 2604.00200  
**Year:** 2026

## Summary

This paper presents the first formal treatment of constrained [[rlhf]] with multiple reward oracles in the offline setting. The framework maximizes target population utility subject to minimum protected group welfare constraints, providing finite-sample guarantees for preference-based alignment with fairness considerations.

## Problem Formulation

### Constrained Optimization
Solves the optimization problem:
```
max_π E_π[r*_1] - η D_KL(π|π_0)
s.t. E_π[r*_2] ≥ J_min
```
Where:
- r*_1: Target population utility function
- r*_2: Protected group welfare function  
- π_0: Reference policy
- J_min: Minimum acceptable protected group welfare
- η: KL regularization parameter

### Multiple Oracle Setting
Extends standard single-oracle [[rlhf]] to handle:
- **Target Oracle o_1**: Primary user population preferences
- **Protected Oracle o_2**: Protected group preferences
- **Bradley-Terry Model**: o_k(x,a,a') ~ Ber(σ(r*_k(x,a) - r*_k(x,a')))

## Technical Approach

### Dual-Only Algorithm
1. **Reward Estimation**: Maximum likelihood estimation of oracle-specific rewards
2. **Lagrangian Formulation**: Cast constrained objective as KL-regularized Lagrangian
3. **Gibbs Policy**: Primal optimizer has closed-form Gibbs distribution
4. **Convex Dual**: Reduces learning to convex dual problem with joint policy-multiplier optimization

### Theoretical Guarantees
- **High-probability constraint satisfaction**: Certified feasibility bounds
- **Finite-sample performance**: Non-asymptotic optimality gap analysis
- **Coverage dependence**: Dataset coverage governs both optimality and constraint violation
