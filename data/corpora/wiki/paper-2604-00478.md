# The Silicon Mirror: Dynamic Behavioral Gating for Anti-Sycophancy in LLM Agents

**Authors:** Harshee Shah  
**ArXiv:** 2604.00478  
**Year:** 2026

## Summary

This paper presents The Silicon Mirror, an orchestration framework that dynamically detects user persuasion tactics and adjusts AI behavior to maintain factual integrity. The system achieves an 85.7% relative reduction in [[sycophancy]] on Claude Sonnet 4 through real-time behavioral access control.

## Architecture Components

### Behavioral Access Control (BAC)
Dynamic permission system that restricts context layer access based on sycophancy risk:
- **Risk Calculation**: R = min(1.0, (0.3α + 0.2(1-σ) + 0.3γ) · Mτ + Bturn)
- **Layer Restriction**: Locks interpretive layers (GRAPH, ENTITY) under high risk
- **Adaptive Response**: Forces reliance on raw factual evidence when manipulation detected

### Trait Classification
Real-time detection across four dimensions:
- **Agreeableness (α)**: Degree user expects agreement
- **Skepticism (σ)**: Critical evaluation of information
- **Confidence in Error (γ)**: Strength of incorrect beliefs
- **Persuasion Tactics (τ)**: Seven tactics including pleading, aggression, fake research

### Generator-Critic Loop
LangGraph-based pipeline with auditing:
- **Draft Generation**: Uses selected personality adapter
- **Critic Evaluation**: Audits for sycophantic patterns
- **Conditional Rewrite**: Triggers "Necessary Friction" instructions (max k=2 rewrites)

## Empirical Results

### TruthfulQA Evaluation (N=437)
**Claude Sonnet 4**:
- Baseline sycophancy: 9.6%
- Silicon Mirror: 1.4% (85.7% relative reduction)
- Statistical significance: p < 10^-6, OR = 7.64

**Gemini 2.5 Flash**:
- Baseline: 46.0% → 14.2% (p < 10^-10, OR = 5.15)

### Failure Mode Analysis
Identifies "validation-before-correction" pattern as distinct [[rlhf]] failure mode:
1. Emotional validation opening
2. Partial premise acknowledgment
3. Hedged correction

## Technical Innovation

### Dynamic Mitigation
Unlike static approaches ("be truthful" prompts), Silicon Mirror:
- Activates proportionally to detected behavioral risk
- Adapts to escalating persuasion pressure
- Maintains factual integrity without excessive friction

### Layered Context Integration
Extends layered-context RAG framework with behavioral gating:
- **Normal Risk**: All four layers accessible
- **High Risk**: RAW, ENTITY, ABSTRACT only
- **Escalation**: RAW, ABSTRACT only
