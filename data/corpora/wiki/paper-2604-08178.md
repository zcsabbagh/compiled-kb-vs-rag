# Aligning Agents via Planning: A Benchmark for Trajectory-Level Reward Modeling

**Authors:** Jiaxuan Wang, Yulan Hu, Wenjin Yang, Zheng Pan, Xin Li, Lan-Zhe Guo  
**ArXiv:** 2604.08178  
**Year:** 2026

## Summary

This paper introduces Plan-RewardBench, the first trajectory-level preference benchmark designed to evaluate reward models on complex tool-integrated agent scenarios. Unlike existing benchmarks that focus on response-level preferences, Plan-RewardBench assesses multi-step planning, tool execution, and error recovery.

## Key Contributions

### Plan-RewardBench Benchmark
A trajectory-level preference dataset covering four representative task families:
- **Safety Refusal**: Trajectory-level safety decisions where worst unsafe episode determines label
- **Tool-Irrelevance/Unavailability**: Handling missing or inappropriate tools
- **Complex Planning**: Multi-step reasoning and tool coordination
- **Robust Error Recovery**: Graceful handling of tool failures and environmental changes

### Construction Pipeline
Multi-source approach combining:
- **Natural Rollouts** (70%): Diverse agent executions using multiple models and configurations
- **Rule-Based Perturbations** (22%): Systematic injection of common failure modes
- **Minimal-Edit Perturbations** (8%): LLM-generated hard negatives controlling for length/format bias

### Evaluation Protocol
Pairwise trajectory comparison with:
- **Multi-LLM Judge Panel**: Consensus scoring with meta-review filtering
- **Bias Control**: Length and format balancing to isolate semantic failures
- **Hard Negatives**: Confusable distractors that test genuine understanding

## Empirical Results

### Performance Degradation
All three evaluator families (generative RMs, discriminative RMs, LLM-as-Judge) show:
- **Sharp degradation** on long-horizon trajectories
- **Substantial challenges** across all task categories
- **Need for specialized training** in agentic reward modeling

### Failure Mode Analysis
- **Tool-Grounded Fabrication**: Fluent responses contradicting tool outputs
- **Planning Inconsistency**: Multi-step reasoning breakdowns
- **Recovery Failures**: Poor handling of tool errors and environmental changes

## Technical Details

### Data Sources
- **Base**: Toucan dataset with realistic MCP tool registries
- **Expansion**: Multi-agent rollouts using Qwen-Agent and OpenAI-Agent
- **Scale**: Comprehensive coverage across diverse tool environments

### Quality Control
- **Human Audit**: Expert validation of preference labels
- **Consistency Testing**: Inter-annotator agreement protocols
- **Artifact Detection**: Systematic removal of low-signal negatives

## Implications

Highlights critical gap in current reward modeling capabilities for agentic systems. Provides both evaluation suite and blueprint for constructing trajectory-level preference data for [[rlhf]] in tool-augmented environments.
