# SenseAI: A Human-in-the-Loop Dataset for RLHF-Aligned Financial Sentiment Reasoning

**Authors:** Berny Kabalisa  
**ArXiv:** 2604.05135  
**Year:** 2026

## Summary

This paper introduces SenseAI, a proprietary dataset of human-in-the-loop validated financial sentiment data designed specifically for [[rlhf]] training. The dataset captures not only sentiment classifications but the full decision-making context including AI reasoning chains, expert corrections, and market outcome validation.

## Dataset Design

### Core Structure
Spanning 1,439 labeled data points across 40 US-listed equities and 13 financial categories, each entry contains:
- **AI-Generated Analysis**: Full reasoning chain supporting sentiment classification
- **Expert Corrections**: Human financial expert validation and correction signals
- **Confidence Scores**: Model self-assessed certainty percentages
- **Market Validation**: Real price outcomes 4 hours post-classification
- **Metadata**: Timestamps, model versions, edit types

### RLHF Structural Alignment
Satisfies three key RLHF requirements:
1. **Human Preference Signals**: Expert correction annotations
2. **Correction Context**: What preferred outputs look like
3. **Reasoning Chains**: Full cognitive context enabling pattern learning

### Collection Methodology
**Human-in-the-Loop Engine**: AI generates sentiment interpretations of financial news headlines, systematically reviewed by human expert. Each correction constitutes high-signal training data showing where AI reasoning diverges from expert judgment.

**Quality Control**: 90% annotation consistency target with self-consistency testing protocol.

## Key Empirical Findings

### Novel Behavioral Patterns
1. **Latent Reasoning Drift**: First documented observation in financial NLP - model reasoning quality degrades over time even with consistent outputs
2. **Systematic Confidence Over-Hedging**: Models consistently underestimate their accuracy in financial contexts
3. **Forward Projection**: Tendency to project current trends inappropriately into future scenarios
4. **Goldilocks Zone**: Measurable range of correctable model error optimal for fine-tuning
5. **Sentiment Hypersensitivity**: Excessive sensitivity to linguistic qualifiers in financial text
6. **Model Version Effects**: Systematic differences in error patterns across model iterations

### Correction Statistics
- **HITL Correction Rate**: Quantified human intervention frequency
- **Edit Type Distribution**: Categorized correction severity (0-3 scale)
- **Confidence Calibration**: Relationship between stated confidence and actual accuracy

## Commercial Applications

### Enterprise AI Deployment
- **Financial Agent Training**: Direct integration into LLM fine-tuning pipelines
- **Risk Assessment**: Real-world market validation enables outcome-based training
- **Analyst Augmentation**: Human-AI collaboration patterns for financial decision-making

### Competitive Advantages
- **Proprietary Data**: Continuously collected, structurally irreproducible
- **Domain Specificity**: Addresses "data wall" through specialized high-quality signals
- **RLHF Ready**: No preprocessing required for modern training pipelines

## Technical Innovation

### Beyond Existing Benchmarks
Unlike FinancialPhraseBank and similar datasets, SenseAI captures:
- **Reasoning Process**: How experts reach conclusions, not just final labels
- **Error Patterns**: Where and why AI reasoning fails
- **Market Grounding**: External validation through price movements

### Data Engine Architecture
- **Continuous Collection**: Ongoing data generation since December 2024
- **Multi-Dimensional Schema**: 13-field structure capturing full context
- **Version Tracking**: Model evolution effects on reasoning quality

## Implications

Validates core thesis that general-purpose language models operate in predictable, correctable error regime for financial reasoning. High-quality HITL correction data is both necessary and sufficient for targeted improvement through fine-tuning.
