# ReflectRM

ReflectRM is a generative reward model framework introduced in [[paper-2604-07506]] that leverages self-reflection to assess analytical quality and enhance preference modeling. Unlike existing approaches that focus on outcome-level supervision, ReflectRM provides explicit supervision over the analytical reasoning process.

## Core Innovation

### Unified Judgment Framework
Formulates both response preference and analysis preference as a single conditional generative process:

**Response Preference**: (a, p) ∼ fθ(· | q; r1, r2)  
**Analysis Preference**: (a', p') ∼ fθ(· | q, r1, r2; a1, a2)

This enables the model to act as both judge and meta-judge, evaluating its own reasoning quality without auxiliary models.

### Mutually Reinforcing Capabilities
The unified framework induces two complementary abilities:
1. **Pairwise Response Preference**: Core reward modeling capability
2. **Pairwise Analysis Preference**: Self-reflection on reasoning quality

These capabilities strengthen each other through joint training, creating more robust evaluative logic.

## Training Methodology

### Dual Data Types
**Preference Data**: Standard (query, response_pair, label) tuples for core reward modeling.

**Reflection Data**: Process-level preferences comparing analytical traces leading to correct vs. incorrect outcomes. Generated by creating multiple outputs for preference data and pairing analyses based on prediction correctness.

### Unified Training Objective
Both data types guide the same core preference judgment capability rather than serving as separate objectives, preventing task conflict and enabling seamless integration.

## Two-Stage Inference

### Stage 1: Rollouts and Anchor Selection
- Generate N=8 candidate analyses using response preference capability
- Select highest-confidence output as anchor using bottom-10% token probabilities
- Confidence score: average log-probability of lowest-confidence tokens

### Stage 2: Self-Reflection and Voting
- Use analysis preference capability to compare remaining candidates against anchor
- Aggregate multiple reliable analyses for final prediction
- Leverage self-reflection to identify and correct reasoning errors

## Empirical Results

### Performance Improvements
- **Average Gain**: +3.7 accuracy improvement on Qwen3-4B across four benchmarks
- **Consistency**: Benefits across multiple model scales and evaluation settings
- **Mutual Reinforcement**: Response and analysis preferences demonstrably strengthen each other

### Positional Bias Mitigation
- **Substantial Reduction**: +10.2 improvement in positional consistency vs. leading GRMs
- **Stability**: More reliable evaluation across different input orderings
- **Robustness**: Self-reflection helps identify position-dependent errors

## Technical Advantages

### No Auxiliary Models
Unlike approaches requiring external process evaluators, ReflectRM's self-reflection is inherent to the model architecture.

### Single Training Pipeline
Unified objective eliminates need for complex multi-stage training or separate process evaluation models.

### Confidence-Guided Selection
Uses generation probability patterns to identify most reliable analyses, providing principled anchor selection.

## Applications

- **RLHF Enhancement**: Improved reward modeling through process supervision
- **Evaluation Reliability**: More stable and consistent preference judgments
- **Reasoning Quality**: Explicit supervision of analytical processes
- **Bias Mitigation**: Systematic reduction of positional and presentation effects
