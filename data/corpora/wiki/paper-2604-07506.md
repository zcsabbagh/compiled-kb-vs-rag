# ReflectRM: Boosting Generative Reward Models via Self-Reflection within a Unified Judgment Framework

**Authors:** Kai Qin, Liangxin Liu, Yu Liang, Longzheng Wang, Yan Wang, Yueyang Zhang, Long Xia, Zhiyuan Sun, Houde Liu, Daiting Shi  
**ArXiv:** 2604.07506  
**Year:** 2026

## Summary

This paper introduces ReflectRM, a novel generative reward model that leverages self-reflection to assess analytical quality and enhance preference modeling. Unlike existing methods that focus on outcome-level supervision, ReflectRM provides explicit supervision over the analytical reasoning process.

## Key Contributions

### Unified Judgment Framework
Formulates both response preference and analysis preference as a single conditional generative process:
- **Response Preference**: (a, p) ∼ fθ(· | q; r1, r2) for query q and responses (r1, r2)
- **Analysis Preference**: (a', p') ∼ fθ(· | q, r1, r2; a1, a2) for analytical processes (a1, a2)

This enables joint modeling where the model acts as both judge and meta-judge of its own reasoning.

### Training Methodology
**Dual Data Types**:
- **Preference Data**: Standard (query, response_pair, label) tuples
- **Reflection Data**: Process-level preferences comparing analytical traces leading to correct vs. incorrect outcomes

**Unified Training**: Both data types guide the same core preference judgment capability, creating mutually reinforcing response and analysis preferences.

### Two-Stage Inference
1. **Rollouts and Anchor Selection**: Generate N=8 candidate analyses, select highest-confidence output as anchor using bottom-10% token probabilities
2. **Self-Reflection and Voting**: Use self-reflection to compare remaining candidates against anchor, aggregate reliable analyses for final prediction

## Empirical Results

### Performance Gains
- **Average Improvement**: +3.7 accuracy gain on Qwen3-4B across four benchmarks
- **Consistent Benefits**: Improvements across multiple model scales and evaluation settings
- **Mutual Reinforcement**: Response preference and analysis preference capabilities strengthen each other

### Positional Bias Mitigation
- **Substantial Reduction**: +10.2 improvement in positional consistency compared to leading GRMs
- **Stability**: More reliable evaluator across different input orderings
- **Robustness**: Self-reflection helps identify and correct position-dependent errors

## Technical Innovation

### Self-Reflection Mechanism
Model evaluates quality of its own analytical processes without requiring:
- **Auxiliary Models**: No external process evaluators needed
- **Complex Pipelines**: Single unified training objective
- **Multi-Stage Training**: Joint optimization from start

### Confidence-Guided Selection
Uses generation probability patterns to identify most reliable analyses:
- **Bottom-10% Tokens**: Focus on lowest-probability tokens as confidence indicator
- **Anchor Selection**: Highest-confidence analysis serves as comparison baseline
- **Aggregation**: Multiple reliable analyses combined for final judgment

## Implications

Demonstrates that explicit process supervision significantly improves generative reward models. The unified framework shows that response judgment and analytical quality assessment are complementary capabilities that can be jointly optimized.
