# Beyond Semantic Manipulation: Token-Space Attacks on Reward Models

**Authors:** Yuheng Zhang, Mingyue Huo, Minghao Zhu, Mengxue Zhang, Nan Jiang  
**ArXiv:** 2604.02686  
**Year:** 2026

## Summary

This paper introduces Token Mapping Perturbation Attack (TOMPA), a novel framework that performs adversarial optimization directly in token space to exploit [[reward-hacking]] vulnerabilities in [[rlhf]] systems. Unlike existing attacks that operate within semantic space, TOMPA bypasses the decode-re-tokenize interface to discover non-linguistic token patterns that achieve extremely high rewards.

## Key Innovation

### Token-Space Attack Framework
TOMPA operates by:
- **Direct Token Manipulation**: Bypassing standard decode-re-tokenize pipeline
- **Perturbation Mapping**: Applying transformations directly to token sequences before reward model evaluation
- **RL-Based Discovery**: Using [[grpo]] with black-box scalar feedback to automatically find adversarial patterns
- **Non-Linguistic Exploitation**: Generating gibberish that receives high rewards

### Attack Results
On Skywork-Reward-V2-Llama-3.1-8B (top-ranked on RewardBench):
- **Mean Reward**: +33.64 vs GPT-5 reference score of +17.48 (nearly doubled)
- **Beat Rate**: 98.0% success rate against GPT-5 reference answers
- **Output Quality**: Completely non-linguistic gibberish consisting of repetitive fragments, cross-lingual tokens, and reserved tokenizer artifacts

## Technical Approach

### GRPO-Based Optimization
Uses Group Relative Policy Optimization to:
- Generate multiple responses per prompt (G generations)
- Compare within groups rather than against fixed references
- Update policy based on relative rankings with KL regularization
- Automatically discover adversarial token patterns through RL

### Beyond OOD Effects
Demonstrates this is not trivial out-of-distribution behavior:
- **Random OOD Baseline**: Yields strongly negative rewards and near-zero beat rates
- **Length Dependency**: Adversarial patterns become highly rewarded only at sufficient sequence lengths
- **Systematic Exploitation**: High scores arise from learned optimization, not arbitrary inputs

## Implications

### Critical Vulnerability
Reveals that reward models can be systematically exploited beyond semantic regime, exposing fundamental weaknesses in current [[rlhf]] pipelines that cannot be addressed through semantic-level defenses.

### Attack Taxonomy
First approach combining:
- **RL-based method** (vs manual construction)
- **Non-linguistic content** (vs human-readable)
- **Black-box access** (vs gradient or auxiliary model requirements)
