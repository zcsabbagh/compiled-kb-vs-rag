# One Model for All: Multi-Objective Controllable Language Models

**Authors:** Qiang He, Yucheng Yang, Tianyi Zhou, Meng Fang, Mykola Pechenizkiy, Setareh Maghsudi  
**ArXiv:** 2604.04497  
**Year:** 2026

## Summary

This paper introduces Multi-Objective Control (MOC), a novel approach that trains a single LLM to generate personalized responses across diverse user preferences on the Pareto front. Unlike traditional [[rlhf]] which optimizes for fixed, developer-chosen preferences, MOC enables dynamic balancing of multiple objectives according to user-specified preference vectors.

## Key Contributions

### Multi-Objective Control Algorithm
MOC formulates controllable LLM training as a constrained optimization problem:
- **Preference Vectors**: p = [p1, p2, ..., pN] where Σpi = 1, representing importance weights for N objectives
- **Constraint**: MSE between expected reward vector and preference vector ≤ ϕ
- **Relaxation**: Transforms constrained problem into dual-objective optimization with hinge penalty

### Training Methodology
**Prompt Modification**: Prepends preference vector to original prompt as ⟨R1⟩p1⟨R2⟩p2...⟨RN⟩pN{prompt}

**Scalarized Optimization**: Uses dynamic weighting across training steps, maintaining computational cost comparable to single-objective [[rlhf]]

**LoRA Integration**: Enables fine-tuning 7B parameter models on single A6000 GPU

## Empirical Results

### Performance Metrics
- **Controllability**: Clear monotonic relationship between input preferences and model outputs
- **Solution Quality**: Superior Pareto front measured by hyper-volume metric
- **Generalization**: Robust handling of unseen preference combinations

### Comparison to Baselines
Outperforms existing methods across three dimensions:
- MORLHF: Requires M separate models vs. MOC's single model
- Rewarded Soups: No explicit policy improvement vs. MOC's principled optimization
- MODPO: Requires preference data vs. MOC's data-free approach

## Technical Innovation

MOC addresses two key challenges in multi-objective LLM alignment:
1. **Control Target Selection**: Uses reward signals rather than loss functions as control targets
2. **Computational Feasibility**: Relaxes complex multi-constraint problem into tractable dual-objective form

## Applications

Enables personalized LLMs that dynamically balance trade-offs between:
- Empathy vs. task-oriented efficiency
- Safety vs. creativity
- Helpfulness vs. conciseness
