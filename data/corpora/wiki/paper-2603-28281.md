# Corruption-robust Offline Multi-agent Reinforcement Learning From Human Feedback

**Authors:** Andi Nika, Debmalya Mandal, Parameswaran Kamalaruban, Adish Singla, Goran Radanović  
**ArXiv:** 2603.28281  
**Year:** 2026

## Summary

This paper introduces the first systematic treatment of adversarial data corruption in offline multi-agent [[rlhf]] (MARLHF). The work extends corruption-robust methods from single-agent settings to multi-agent environments using linear Markov games, achieving optimal O(ε^(1-o(1))) bounds under uniform coverage and O(√ε) bounds under unilateral coverage.

## Problem Formulation

### Multi-Agent RLHF Setting
- **Preference Data**: Tuples (τ, τ', o) where o is n-dimensional binary vector representing each agent's preferences
- **Corruption Model**: ε-fraction of dataset arbitrarily corrupted by adversary
- **Linear Markov Games**: Framework with feature map φ: S × A → R^d for tractable analysis

### Key Challenges
Unlike single-agent settings, MARLHF faces:
- **Multiple Reward Models**: Uncertainty over n different reward functions
- **Nash Equilibrium Computation**: Intractable for general-sum games
- **Coverage Assumptions**: Unilateral coverage more challenging than uniform coverage

## Technical Contributions

### Uniform Coverage Results
- **Algorithm**: Robust reward estimation followed by value-based backward induction
- **Guarantee**: O(nε^(1-o(1)) + n/√m) Nash gap bound
- **Optimality**: Matches single-agent corruption dependence

### Unilateral Coverage Extension
- **Method**: Projected gradient ascent with biased gradient estimation
- **Innovation**: Uses Nash equilibrium gradient as proxy for current policy gradient
- **Bound**: O(n√ε + n/√m + n/√T₁) Nash gap

### Computational Tractability
- **Relaxation**: Nash equilibrium to Coarse Correlated Equilibrium (CCE)
- **Algorithm**: Optimistic Hedge for convex-concave stage games
- **Efficiency**: Quasi-polynomial time with same √ε dependence

## Theoretical Analysis

### Robust Reward Aggregation
Critical challenge of combining diverse group preferences:
- **Average Aggregation**: Systematically under-aligns worst-performing groups
- **Min Aggregation**: Sacrifices overall performance for worst-case fairness
- **APPA Framework**: Adaptive aggregation based on historical performance

### Coverage Requirements
- **Uniform Coverage**: All policy directions sufficiently represented
- **Unilateral Coverage**: Only Nash equilibrium and single-player deviations covered
- **Feature Covariance**: Σ_μ(h) and Σ^-_{μ,μ_ref} matrices determine coverage quality
