# SDVDiag: Using Context-Aware Causality Mining for the Diagnosis of Connected Vehicle Functions

**Authors:** Matthias Weiß, Falk Dettinger, Elias Detrois, Nasser Jazdi, Michael Weyrich  
**ArXiv:** 2604.03391  
**Year:** 2026

## Summary

This paper introduces SDVDiag, a multimodal framework for diagnosing connected vehicle functions that integrates [[rlhf]] with causality mining to achieve 100% precision in causal edge detection. The system addresses the challenge of diagnosing distributed vehicle systems by combining automated analysis with human expert knowledge through continuous reinforcement learning.

## Core Innovation

### Context-Aware Causality Mining
SDVDiag extends traditional data-driven causal discovery by incorporating:
- **Human Expert Feedback**: [[rlhf]] framework for continuous model training with domain expertise
- **Multimodal Data Integration**: Combines performance metrics, distributed traces, and system topology
- **Context Injection**: Rule-based interface for domain-specific relationships and hidden dependencies

### Architecture Components
1. **Data Collection**: Prometheus metrics and Zipkin distributed tracing
2. **GNN Encoder**: Graph Neural Network with contrastive learning for causal embeddings
3. **RL Feedback Loop**: Hierarchical reinforcement learning with persistent expert knowledge storage
4. **Context Refinement**: Topology-based pruning and domain rule integration

## Technical Approach

### Graph Neural Network Encoder
- **Contrastive Learning**: Triplet-based training (anchor, positive, negative examples)
- **Embedding Objective**: Causally connected services mapped to similar vector representations
- **Architecture Support**: Modular design supporting GCN and GAT variants
- **Transfer Learning**: Frozen encoder enables cross-system deployment

### Reinforcement Learning Integration
Extends Wang et al.'s hierarchical approach with:
- **Efficient Querying**: Pairwise comparisons reduce human input from O(N²) to manageable scale
- **Persistent Storage**: Knowledge database preserves expert feedback across retraining cycles
- **Continuous Adaptation**: Handles dynamic system changes without full retraining

## Experimental Results

### Automated Valet Parking Evaluation
Tested on connected vehicle test field with distributed parking application:
- **Precision Improvement**: 14% → 100% for causal edge detection
- **System Interpretability**: Significant enhancement over purely data-driven approaches
- **Real-World Validation**: Demonstrated effectiveness in Multi-Access Edge Computing environment

### Performance Metrics
- **False Positive Reduction**: Context-aware pruning eliminates spurious causal links
- **Expert Knowledge Integration**: Successful incorporation of domain-specific relationships
- **Scalability**: Efficient operation across distributed vehicle infrastructure

### Novel Integration Framework
- **Multimodal Analysis**: First system combining metrics, traces, and topology for vehicle diagnosis
