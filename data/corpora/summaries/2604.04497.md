# One Model for All: Multi-Objective Controllable Language Models

## Contributions

The paper introduces Multi-Objective Control (MOC), a novel algorithm that enables a single large language model to generate personalized responses across diverse user preferences without requiring multiple training runs. The key contributions are:

1. **Single-model multi-objective controllability**: MOC trains one LLM that can dynamically adjust its behavior based on user-specified preference vectors, eliminating the need for separate models for each preference configuration.

2. **Computational efficiency**: The algorithm achieves comparable computational cost to single-objective RLHF while handling multiple objectives, making it feasible to fine-tune a 7B-parameter model on a single A6000 GPU using LoRA.

3. **Principled multi-objective optimization**: MOC incorporates multi-objective optimization principles into RLHF by treating preference constraints as additional objectives and using dynamic weighting with scalarization.

## Methods

The approach formulates multi-objective controllability as a constrained optimization problem where the policy must satisfy multiple preference vectors simultaneously. Key methodological components include:

**Problem Formulation**: The training objective is formulated as:
```
max J(π(·; θ, p)) subject to Φ(π(·; θ, p), p) ≤ ϕ, ∀p ∈ {p₁, p₂, ..., pₘ}
```
where π is the policy conditioned on preference vector p, and Φ measures deviation from preferences using MSE between expected reward vectors and preference vectors.

**Preference Vector Integration**: User preferences are represented as normalized vectors p = [p₁, p₂, ..., pₙ] where Σpᵢ = 1 and pᵢ ≥ 0. These are prepended to prompts as: `⟨R₁⟩p₁⟨R₂⟩p₂...⟨Rₙ⟩pₙ{prompt}`.

**Optimization Strategy**: The constrained problem is relaxed into a bi-objective optimization and then scalarized using dynamic weights c⁽ⁱ⁾ determined by solving a min-norm problem. A computationally efficient surrogate objective is derived that avoids expensive backpropagation operations.

**Surrogate Objective**: Theorem 1 provides an upper bound that enables efficient computation without additional backpropagation, using PPO's advantage function and clipping mechanisms.

## Key Results

**Controllability Performance**: MOC achieves perfect Kendall's tau correlation of 1.00 in both humor-helpful and harmless-helpful settings, significantly outperforming baselines (RiC: 0.85 average, MORLHF: 1.00 average, Rewarded Soups: 0.98 average).

**Solution Quality**: MOC demonstrates superior hyper-volume performance, achieving 14.176 in humor-helpful settings compared to RiC's 6.692, indicating better convergence to the Pareto front and solution diversity.

**Computational Efficiency**: Training cost is comparable to single-objective RLHF, with successful fine-tuning of 7B-parameter models on a single A6000 GPU using LoRA with rank 64.

**Generalization**: The method shows robust performance on unseen preference vectors while maintaining both alignment quality and diversity.

**Illustrative Example**: On the fishwood task, MOC solutions lie on the Pareto front and align closely with preference vectors, while Linear PPO fails to consistently follow different preference vectors due to objective dominance.

## Limitations

**Evaluation Scope**: The experiments are limited to reward-model-based evaluation rather than human evaluation, following standard RLHF practice but potentially missing nuanced human preferences.

**Preference Vector Constraints**: The method requires predefined preference vectors during training ({[0.0, 1], [0.1, 0.9], ..., [0.9, 0.1], [1, 0.0]}), which may limit flexibility for completely novel preference combinations.

**Computational Constraints**: While efficient, the method still requires 8-bit model loading due to computational limitations, potentially affecting model performance.

**Limited Objective Pairs**: Experiments focus on two-objective scenarios (humor-helpful, harmless-helpful), and scalability to higher-dimensional preference spaces remains unclear.

**Theoretical Guarantees**: The surrogate objective provides an upper bound but the relationship between this bound and actual performance optimality is not thoroughly characterized.

**Baseline Comparisons**: Some baseline methods (like MORLHF) also achieve perfect Kendall's tau correlation, making it difficult to distinguish performance advantages in certain metrics.
