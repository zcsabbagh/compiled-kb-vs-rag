# Offline Constrained RLHF with Multiple Preference Oracles

## Contributions

- **First formal treatment** of constrained RLHF with multiple reward oracles, integrating preference-based reward estimation and constraint satisfaction into a unified framework
- **Dual-only algorithm** that jointly optimizes the policy and Lagrange multiplier using reward estimates from offline pairwise comparisons provided by both oracles
- **Non-asymptotic guarantees** providing both sample-dependent and sample-independent bounds showing how dataset coverage governs optimality gap and constraint violation
- **General framework** extending bounds to multiple constraints and general f-divergence regularization
- **First finite-sample guarantees** for constrained RLHF with multiple reward oracles in the offline setting

## Methods

The paper formulates constrained RLHF as maximizing target population utility subject to protected group welfare constraints:

```
max_π E_π[r*_1] - η D_KL(π|π_0)
s.t. E_π[r*_2] ≥ J_min
```

**Key methodological components:**

- **Bradley-Terry preference model**: Binary preferences follow `o_k(x,a,a') ~ Ber(σ(r*_k(x,a) - r*_k(x,a')))` for oracles k∈{1,2}
- **Maximum likelihood estimation**: Separate MLEs for each oracle's reward function under linear reward assumption `r*_k(x,a) = ⟨θ*_k, φ(x,a)⟩`
- **Lagrangian formulation**: Cast as KL-regularized Lagrangian with Gibbs policy as primal optimizer, reducing to convex dual problem
- **Dual-only algorithm**: Projected gradient descent on dual variable λ with step size α = η/B² and closed-form Gibbs policy updates

**Key assumptions:**
- Full coverage of reference policy π₀
- Linear rewards with bounded parameters ∥θ*_k∥ ≤ B
- Identifiability condition ensuring unique parameter recovery

## Key Results

**Statistical guarantees:** With probability at least 1-2δ, the estimation error satisfies:
```
∥θ̂_k - θ*_k∥_{Σ_N,reg} ≤ C√((d + log(1/δ))/(γ²N)) + λ_reg B² =: β_N
```

**Dual function approximation:** With probability at least 1-2δ:
```
|ĝ(λ) - g(λ)| ≤ (1+λ)β_N/√λ_min(Σ_N,reg)
|ĝ'(λ) - g'(λ)| ≤ β_N/√λ_min(Σ_N,reg) · (1 + B(1+λ)/η)
```

**Algorithm performance:** With step size α = η/B² and T iterations:
```
g(λ̄_T) - g(λ*) ≤ 2E_g(R) + B²R²/(2ηT)
(J_min - E_{π*_{λ̄_T}}[r*_2])_+ ≤ E_g'(R) + B²R/(η√T)
J(π*) - J(π*_{λ̄_T}) ≤ 2E_g(R) + B²R²/(2ηT) + RE_g'(R) + B²R²/(η√T)
```

**Empirical validation:** On PKU-SafeRLHF dataset with 74,000 training examples, the algorithm demonstrates rapid constraint violation decay and strong correlation between policy shifts and reward differentials.

## Limitations

- **Linear reward assumption** may be restrictive for complex preference structures in practice
- **Separate MLE approach** doesn't exploit potential correlations between oracles, which could improve error constants
- **Full coverage requirement** on reference policy may be violated in practice with neural language models
- **Adaptive step size** used in experiments deviates from theoretical guarantees, creating a theory-practice gap
- **Single constraint focus** in main analysis, though extensions to multiple constraints are provided
- **Offline setting limitation** prevents adaptation based on learned policy performance
- **Identifiability assumption** requires spanning condition that may not hold with insufficient data diversity
- **Computational complexity** scales with feature dimension d and may be prohibitive for high-dimensional embeddings
