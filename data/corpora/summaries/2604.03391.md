# SDVDiag: Using Context-Aware Causality Mining for the Diagnosis of Connected Vehicle Functions

## Contributions

The paper presents three main contributions to address the challenges of diagnosing connected vehicle systems:

1. **Reinforcement learning framework with human feedback integration**: A hierarchical reinforcement learning system that efficiently incorporates expert knowledge into causal discovery while preserving feedback in a persistent knowledge database for continuous learning.

2. **Multimodal analysis pipeline**: A system that simultaneously captures different performance metrics and system topology, combining Prometheus time series data with Zipkin distributed tracing for comprehensive causal analysis.

3. **Rule-based context integration interface**: An extensible mechanism for incorporating domain-specific information, including hidden relationships and application data that may not be directly observable through standard monitoring.

## Methods

The SDVDiag approach consists of several integrated components:

**Data Collection and Encoding**: The system uses Prometheus for performance metrics collection and Zipkin for distributed tracing. A Graph Neural Network (GNN) encoder transforms multivariate time series data into embeddings using contrastive learning, where causally connected services are mapped to similar vector representations.

**Human Feedback Integration**: The system employs hierarchical reinforcement learning with two policy levels. The low-level policy uses Deep Deterministic Policy Gradient (DDPG) to generate edge probabilities, while the high-level policy uses Q-learning with ε-greedy exploration to select informative target nodes. Expert feedback is collected through pairwise comparisons of triplets rather than exhaustive edge labeling, reducing complexity from O(N²) to more manageable levels.

**Context-Aware Refinement**: A three-stage pruning process validates learned edges: confidence filtering removes low-probability edges, trace validation cross-references against Zipkin dependency graphs, and duplicate aggregation consolidates multiple metric-level edges between service pairs. The context extension module allows injection of expert-defined causal relationships through structured rules.

## Key Results

The evaluation was conducted on an Automated Valet Parking (AVP) application with seven services running on a Kubernetes cluster. Key quantitative results include:

- **Precision improvement**: From 14% (raw base policy) to 100% (final pruned graph)
- **Graph size reduction**: From 137 edges (raw) to 16 edges (final) after processing
- **Recall maintained**: 84% recall achieved in the final graph
- **F1 score improvement**: From 24% (raw) to 91% (final)
- **Expert feedback efficiency**: Only 30 expert responses were needed to train the reward model
- **Processing stages**: Feedback-adjusted intermediate graph contained 49 edges with 32% precision and 84% recall

The context extension module successfully identified hidden causal factors (parking queue overflow) that don't appear in standard telemetry, enabling accurate root cause analysis that correctly attributed system failures to actual causes rather than downstream effects.

## Limitations

Several significant limitations are acknowledged:

**Scale limitations**: The evaluation was conducted on a relatively small system with only seven services. Scalability to larger microservice architectures with hundreds of components remains unvalidated.

**Ground truth dependency**: The evaluation relies on expert projections rather than definitive causal knowledge, which represents a fundamental challenge in causal discovery validation.

**Limited error scenario data**: The available data regarding error scenarios was constrained, as accurate simulation of failure patterns through error injection remains difficult in experimental environments.

**Encoder accuracy inheritance**: The GNN encoder training uses conventional causal discovery algorithms (PC algorithm, GES) to generate initial ground truth, meaning the embeddings inherit inaccuracies from these imprecise algorithms.

**Abstraction level mismatch**: The system faces challenges in bridging the gap between pod-metric granularity in the multimodal graph and service-level dependencies captured by Zipkin tracing.
