# ReflectRM: Boosting Generative Reward Models via Self-Reflection within a Unified Judgment Framework

## Contributions

- **Unified Judgment Framework**: Proposes a novel framework that models both response preference and analysis preference as a single conditional generative process, enabling unified training of both capabilities within the same model.

- **Self-Reflection Integration**: Introduces ReflectRM, which inherently leverages self-reflection to enhance judgments without requiring auxiliary models or complex training pipelines, addressing the limitation of existing methods that focus primarily on outcome-level supervision.

- **Mutual Reinforcement Discovery**: Demonstrates that response preference and self-reflection capabilities are mutually reinforcing, leading to more robust evaluative logic and substantial mitigation of positional bias.

- **Two-Stage Inference Strategy**: Develops a confidence-guided inference approach that uses self-reflection to identify the most reliable analyses from multiple candidate outputs for final prediction.

## Methods

**Unified Framework**: The core approach formulates all preference tasks as a conditional generative process: `(a, p) ∼ fθ(· | ϕ; δ)`, where analysis `a` and prediction `p` are generated given condition `ϕ` and candidates `δ`. This enables two capabilities:
- Pairwise Response Preference: `(a, p) ∼ fθ(· | q; r1, r2)` for judging between responses
- Pairwise Analysis Preference (Self-Reflection): `(a', p') ∼ fθ(· | q, r1, r2; a1, a2)` for evaluating analytical processes

**Training Data**: Uses standard Preference Data (Pref.) mixed with novel Reflection Data (Refl.) in a 4:1 ratio. Reflection data is constructed by pairing analyses based on correctness of their predictions to provide process-level supervision.

**Two-Stage Inference**:
1. **Stage 1**: Generate N=8 rollouts and select high-confidence anchor using bottom 10% token probabilities: `Conf(Oi) = (1/|Tbottom|) Σ log P(tj)`
2. **Stage 2**: Use self-reflection to compare other candidates against anchor, collect winners into group W, and determine final prediction via majority voting

**Implementation**: Fine-tuned Qwen3 models (4B, 8B, 14B) using Group Relative Policy Optimization (GRPO) for 3 epochs with batch size 64, learning rate 1e-6, and maximum generation length 1024 tokens.

## Key Results

**Main Performance**: ReflectRM achieves consistent improvements across four benchmarks:
- **Qwen3-4B**: +3.7 average accuracy gain (76.4 vs 72.7 baseline)
- **Qwen3-8B**: +2.2 average accuracy gain (77.3 vs 75.1 baseline)
- **Qwen3-14B**: +3.8 average accuracy gain (79.5 vs 75.7 baseline)

**Benchmark-Specific Results** (Qwen3-4B):
- RewardBench: 86.7 vs 84.0 (RFT baseline)
- RM-Bench: 77.7 vs 76.5 (RFT baseline)  
- RMB: 77.1 vs 71.2 (RFT baseline)
- PPE-Preference: 64.2 vs 62.5 (RFT baseline)

**Positional Bias Mitigation**: ReflectRM substantially reduces positional bias:
- **+10.2 improvement** in positional consistency for Qwen3-4B (64.5 vs 54.3 baseline)
- **+3.9 improvement** for Qwen3-8B (63.7 vs 59.8 baseline)
- Nearly **double the consistency gains** compared to standard RFT baseline (+5.4)

**Ablation Studies**:
- Unified training alone provides +2.5 improvement over RFT
- Two-stage inference adds additional +1.2 improvement
- 4:1 preference-to-reflection ratio proves optimal
- Reflection data more effective than simply scaling preference data volume

## Limitations

**Computational Overhead**: The two-stage inference strategy requires generating multiple rollouts (N=8) and performing additional self-reflection comparisons, increasing computational cost during inference compared to single-pass methods.

**Data Construction Dependency**: The method relies on constructing high-quality Reflection Data from existing preference datasets, which may limit applicability when such data is scarce or when base model performance is too low to generate meaningful analytical variations.

**Scale-Dependent Gains**: Performance improvements are more pronounced for smaller models (3.7 points for 4B vs 2.2 points for 8B), suggesting the method may provide diminishing returns as model capacity increases.

**Limited Scope of Self-Reflection**: The self-reflection capability is constrained to evaluating analytical processes within the same domain and format as the training data, potentially limiting generalization to novel analytical frameworks or reasoning patterns.

**Hyperparameter Sensitivity**: The framework introduces several hyperparameters (mixing ratio, number of rollouts, confidence calculation method) that require careful tuning and may not transfer optimally across different model architectures or domains.
