# Relational Preference Encoding in Looped Transformer Internal States

## Contributions

This paper makes several key contributions to understanding how looped transformers encode human preference:

1. **Relational preference encoding discovery**: Demonstrates that Ouro-2.6B-Thinking's loop iteration states encode human preference predominantly relationally rather than absolutely - pairwise access achieves 95.2% test accuracy while the best independent scorer reaches only 65%.

2. **High-accuracy frozen model evaluation**: Achieves 95.2% test accuracy using only ~5M trainable evaluator parameters on a completely frozen 2.6B-parameter base model, surpassing the 84.5% ceiling of an L-BFGS probe by 10.7 percentage points.

3. **Training metric deflation identification**: Documents how misleading training metrics caused by antisymmetry enforcement protocols masked the pairwise model's actual capability across seven consecutive runs, with deflated metrics inversely correlated with actual test performance.

4. **Accidental early stopping discovery**: Shows that the cosine learning rate schedule's dead zone at epoch 2 accidentally preserved the generalization peak, with test accuracy rising from 83.3% (epoch 1) to 95.2% (epoch 2) then degrading to 62.4% (epoch 5).

5. **Flip test diagnostic**: Proposes the flip test as a mandatory diagnostic for pairwise evaluators, demonstrating that antisymmetry correlation (ρ = -0.92 to -0.97) is the robust primary metric while strict sign flip rate reflects scorer bias rather than preference learning.

6. **Nonlinear feature construction benefits**: Demonstrates that nonlinear architectures (attention pooling + GRU) construct rather than destroy preference signal, exceeding both L-BFGS probes and end-to-end reward model baselines.

## Methods

The study uses Ouro-2.6B-Thinking, a 2.6B-parameter looped transformer with iterative refinement capabilities. Key methodological components include:

**Feature Extraction**: Hidden states are extracted from each of 4 loop iterations using forward hooks on the model backbone, producing tensors of shape [batch, seq_len, 2048]. The base model remains completely frozen throughout all experiments. Features are extracted for 50,000 training examples from the Anthropic HH-RLHF dataset, stored as chunked files requiring ~360GB storage.

**Diagnostic Probes**: Three diagnostic analyses characterize the preference signal:
- Pairwise linear probe using logistic regression on chosen-rejected differences
- Independent classification probe on individual responses  
- Structural shortcut analysis examining sequence length, hidden state norms, and activation ratios

**Evaluator Architectures**: Nine architectures spanning three paradigms are tested:
- **Pointwise evaluators**: Score responses independently using attention pooling, LayerNorm, GRU processing, and MLP scoring (~4.7M parameters)
- **Pairwise evaluator**: Processes both responses through shared AttentionPool, computes per-step differences, applies LayerNorm without bias, uses 2-layer GRU with skip connections
- **Linear evaluator**: Single linear layer on concatenated features (8,193 parameters)

**Training Protocol**: Uses AdamW optimizer with gradient clipping, cosine annealing schedule, and critical antisymmetry enforcement through 50% random argument swapping with target sign flipping to prevent degenerate solutions.

## Key Results

**Primary Performance**: The pairwise evaluator achieves 95.2% accuracy on 8,552 unseen test examples at epoch 2, with average score +1.6445 and 95.2% positive rate.

**Access Pattern Comparison**:
- Pairwise nonlinear (GRU + AttentionPool): 95.2% test accuracy
- Pairwise linear (L-BFGS): 84.5% accuracy  
- Independent nonlinear: 65% test accuracy
- Independent linear: 21.75% accuracy (below chance, inverted polarity)

**Diagnostic Results**: 
- Linear probe on pairwise differences: 84.5% accuracy
- Independent classification probe: 21.75% (below chance)
- No structural shortcuts found in sequence length, norms, or activation patterns

**Training Dynamics**: Test accuracy peaks at epoch 2 (95.2%) due to cosine schedule's learning rate dead zone functioning as accidental early stopping, then degrades to 62.4% by epoch 5 as overfitting resumes.

**Flip Test Analysis**: Antisymmetry correlation remains stable at ρ = -0.92 to -0.97 across all epochs, while strict sign flip rate varies from 25% (epoch 2) to 96% (epochs 4-5), tracking scorer bias rather than genuine order sensitivity.

**Error Analysis**: Manual inspection of 30 disagreement cases reveals ~12-15 involve safety-sensitive prompts where the evaluator prefers refusals over harmful responses (contrary to human labels), ~8-10 involve near-identical responses with negligible differences, and fewer than 5 represent clear evaluator errors.

## Limitations

**Single Model Scope**: The study is limited to Ouro-2.6B-Thinking as it is "to our knowledge, the only publicly released looped transformer with documented architecture, open weights, and accessible per-iteration hidden states at a scale suitable for preference learning research." Cross-architecture replication awaits release of comparable models.

**Hardware Constraints**: Feature extraction is limited to 50,000 of 161,000 available training examples due to consumer hardware limitations (RTX 5070 Ti, 12GB VRAM), requiring ~360GB storage and 15 hours extraction time. Full dataset extraction would require ~1.1TB storage.

**Implementation Dependencies**: Requires specific transformers version (4.54.1) due to breaking changes in newer versions that conflict with Ouro's UniversalTransformerCache implementation.

**Interpretive Ambiguity**: The 95.2% accuracy represents "model-internal consistency" measuring how stably Ouro's own learned value system organizes representations rather than agreement with external human annotations - "a fundamentally different claim from 95.2% agreement with external annotators."

**Methodological Complexity**: The antisymmetry enforcement protocol essential for preventing degenerate solutions creates training metric deflation that "went undetected across seven pairwise training runs," requiring careful diagnostic procedures to identify actual model performance.
