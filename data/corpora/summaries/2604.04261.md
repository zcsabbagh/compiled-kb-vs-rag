# APPA: Adaptive Preference Pluralistic Alignment for Fair Federated RLHF of LLMs

## Contributions

1. **Problem Formulation**: Studies pluralistic alignment for LLMs, focusing on aligning with diverse human preferences while promoting fairness across heterogeneous groups in federated settings.

2. **Novel Adaptive Aggregation Algorithm**: Designs an adaptive reward aggregation method that dynamically reweights group-level rewards based on historical alignment rewards, assigning higher weights to under-aligned groups while maintaining non-zero weights for better-aligned ones, without requiring access to raw preference data.

3. **Comprehensive Evaluation**: Evaluates APPA on two Question Answering tasks (GLOBALQA and OQA) across three model families (Gemma-2-2B, Llama-3.2-3B, Qwen3-0.6B), demonstrating consistent improvements over average and min aggregation baselines.

## Methods

**System Architecture**: APPA operates in a Federated Reinforcement Learning from Human Feedback (FedRLHF) setting with N training groups, where each group maintains private preference datasets and acts as a federated client. An aggregation server coordinates policy updates without accessing raw preference data.

**Adaptive Alpha Aggregation**: The core innovation replaces fixed scalar aggregation with group-specific, dynamically updated weights αᵗₘ. The aggregation function uses:
- Average aggregation when Fairness Index (FI) ≥ 0.99
- Log-sum-exp with adaptive weights when FI < 0.99

**Fairness Index**: Quantifies reward disparity using coefficient of variation:
```
FI = (1/|Xᵗ|) Σ 1/(1 + CoV²(qⱼ))
```
where CoV measures relative spread of per-group rewards.

**Adaptive Weight Computation**: Uses exponential moving average (EMA) to track historical alignment:
```
hᵗₘ = λ · hᵗ⁻¹ₘ + (1-λ) · r̄ᵗₘ
```
with λ = 0.8, then computes weights via reversed softmax with temperature T = 0.1.

**Training Process**: Integrates into PPO-based pipeline where server generates rollouts, groups evaluate using local PluralLLM models, and server aggregates rewards using APPA before policy updates.

## Key Results

**GLOBALQA Distributional Preference Alignment (DPA)**:
- **Gemma-2-2B**: APPA achieves JS Avg AS 0.861, Min AS 0.843, FI 0.9994 (highest on all metrics)
- **Llama-3.2-3B**: APPA achieves JS Avg AS 0.848, Min AS 0.834, FI 0.9995 (highest on all metrics)  
- **Qwen3-0.6B**: APPA achieves JS Avg AS 0.824, Min AS 0.809, FI 0.9996 (highest on all metrics)

**GLOBALQA Ordinal Preference Alignment (OPA)**:
- **Gemma-2-2B**: APPA leads with Borda FI 0.891, Avg AS 0.511, Min AS 0.461
- **Llama-3.2-3B**: APPA leads with Borda FI 0.882, Avg AS 0.536, Min AS 0.487
- **Qwen3-0.6B**: APPA achieves Avg AS 0.442, Min AS 0.429

**OQA Results**:
- **Gemma-2-2B & Llama-3.2-3B**: APPA achieves highest Avg AS and Min AS simultaneously (Was. 0.872/0.842 and 0.872/0.841 respectively)
- Consistent improvements of **up to 28%** in worst-group alignment over average aggregation

**Fairness-Alignment Trade-offs**: APPA consistently occupies the upper-right corner in (FI, Min AS) space, achieving both high fairness and strong worst-group performance simultaneously, while average aggregation systematically under-aligns worst-performing groups and min aggregation sacrifices overall alignment.

## Limitations

1. **Model Capacity Dependency**: Performance varies with model size - Qwen3-0.6B shows reduced responsiveness to adaptive weighting on some tasks, with MIN occasionally achieving higher average alignment scores.

2. **Task-Specific Performance**: The method shows different effectiveness across task types, with ranking (OPA) being consistently harder than distributional prediction (DPA), achieving lower absolute scores.

3. **Hyperparameter Sensitivity**: The approach introduces several hyperparameters (λ=0.8, T=0.1, τ=0.99) that may require tuning for different settings, though the paper provides limited analysis of sensitivity to these choices.

4. **Limited Baseline Comparison**: Evaluation focuses primarily on average and min aggregation baselines, with limited comparison to other fairness-aware aggregation methods beyond the fixed-α approach from Park et al. (2024).

5. **Evaluation Scope**: Testing is limited to two question-answering datasets and three model families, potentially limiting generalizability to other domains, tasks, or larger model scales.

6. **PluralLLM Dependency**: The approach relies on frozen PluralLLM models for reward generation, which may introduce biases or limitations from the underlying preference prediction model.
