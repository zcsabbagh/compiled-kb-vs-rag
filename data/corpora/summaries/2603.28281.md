# Corruption-robust Offline Multi-agent Reinforcement Learning From Human Feedback

## Contributions

This paper introduces the first systematic treatment of adversarial data corruption in offline multi-agent reinforcement learning from human feedback (MARLHF). The key contributions are:

1. **Uniform Coverage Algorithm**: Under uniform coverage assumptions, the authors develop a robust estimator that guarantees an O(ϵ^(1-o(1))) bound on the Nash-equilibrium gap, where ϵ is the fraction of corrupted samples.

2. **Unilateral Coverage Algorithm**: For the more challenging unilateral coverage setting (where only a Nash equilibrium and its single-player deviations are covered), they propose an algorithm achieving an O(√ϵ) Nash-gap bound.

3. **Computationally Tractable Solution**: To address computational intractability of Nash equilibrium computation, they relax the solution concept to coarse correlated equilibria (CCE) and derive a quasi-polynomial-time algorithm with O(√ϵ) CCE gap under unilateral coverage.

4. **Theoretical Framework**: They model the problem using linear Markov games with Bradley-Terry preference models and establish corruption-robust guarantees that match optimal dependence rates from single-agent settings.

## Methods

The authors employ a three-stage pipeline across all algorithms:

**Stage 1: Robust Reward Estimation**
- Use TrimmedMLE to robustly estimate reward parameters for each agent from corrupted preference data
- Form confidence sets around estimated parameters based on coverage assumptions

**Stage 2: Robust Q-function Estimation** 
- Apply backward induction with Rob-Q algorithm to estimate value functions
- Use pessimistic/optimistic reward bounds and bonus terms to account for corruption and coverage limitations

**Stage 3: Gap Minimization**
- Minimize estimated Nash gap as proxy for finding equilibrium policies

**Key Technical Innovations:**
- For unilateral coverage: Use projected gradient ascent (PGA) with biased gradient estimates based on feature differences between behavior policies
- For computational tractability: Frame each stage game as saddle-point problem and use Optimistic Hedge algorithm
- Robust mean estimation oracles (RobMean, RobEst) to handle corrupted data

## Key Results

**Uniform Coverage (Algorithm 1):**
- Nash gap bound: O(Hn[ϵ^(1-o(1))/ξ_R + H√d/ξ_P√m])
- Achieves optimal ϵ^(1-o(1)) dependence on corruption level
- Requires sample complexity m ≥ Ω((H^(3/2)/ϵ²)(d + log(n/δ)))

**Unilateral Coverage (Algorithm 4):**
- Nash gap bound: O(H^(5/2)nd^(3/4)√ϵ + H²n√(poly(d))/√m + n/√T₁)
- Achieves O(√ϵ) corruption dependence matching single-agent rates
- T₁ is number of gradient steps in reward estimation

**Coarse Correlated Equilibria (CCE):**
- CCE gap bound: O(H^(5/2)nd^(3/4)√ϵ + H²n√(poly(d))/√m + n/√T₁ + Hn²/T₂)
- Computationally efficient with quasi-polynomial runtime
- T₂ is number of Optimistic Hedge iterations

**Coverage Parameters:**
- ξ_R, ξ_P: uniform coverage coefficients
- C_R, C_P: unilateral coverage coefficients
- All bounds scale linearly with number of agents n

## Limitations

1. **Linear Function Approximation**: The analysis is restricted to linear Markov games, which may not capture the complexity of real-world multi-agent systems. The authors justify this by noting that corruption models for general function approximation are not well-defined for preference data.

2. **Computational Intractability**: Nash equilibrium computation remains intractable for the proposed algorithms under unilateral coverage, necessitating relaxation to CCE for practical implementation.

3. **Coverage Assumptions**: Both uniform and unilateral coverage assumptions may be restrictive in practice. Uniform coverage requires all feature directions to be sufficiently represented, while unilateral coverage requires specific coverage of Nash equilibria and deviations.

4. **Strong Corruption Model**: The ϵ-corruption model assumes adversaries can arbitrarily modify any fraction of the dataset, which may be overly pessimistic compared to more structured attack models.

5. **Sample Complexity**: The required sample sizes scale polynomially with problem parameters and may be prohibitive for high-dimensional problems.

6. **Bradley-Terry Model**: The preference model assumes specific probabilistic structure that may not hold in all applications.

7. **No Empirical Validation**: The paper is purely theoretical with no experimental evaluation of the proposed algorithms on real or synthetic datasets.
